# Genome assembly: manipulating genome assembly files

Now you will manipulate some fasta files. The common output from genome sequencing projects. This dataset comes from the [Darwin Tree of Life Project](https://www.darwintreeoflife.org/). The species we are assembling is the red admiral _Vanessa atalanta_ . 

## 1. Let's connect to the server.
Carlo has sent you the explanation over email. I'm here to help.



## 2. Once connected, let's organise your data
### 1.1. Create a directory
In order to keep your project neat, go to your home folder and make a folder for your work today such as:
```
mkdir genome_assembly_day1
```

## 2. Activate the conda environment

Once connected, activate the conda environment where all programs and dependencies are installed 
```
conda activate /home/ubuntu/miniforge3/envs/genome_assembly
```

## 3. Symlink

All data we are going to need are under `/home/ubuntu/Share/genome_assembly`. But you won't execute anything from there. We are copying files over or making symbolic links to the folders you just created in your home directory.

Make a [symbolic link](https://www.futurelearn.com/info/courses/linux-for-bioinformatics/0/steps/201767#:~:text=A%20symlink%20is%20a%20symbolic,directory%20in%20any%20file%20system.) of scripts to your folder. Do as below:

```
# go inside your folder
cd genome_assembly_day1

#symlink the two scripts
ln -s /home/ubuntu/Share/genome_assembly/asmstats .
ln -s /home/ubuntu/Share/genome_assembly/plot_read_length_dist.py .
```

## 3. Copy

Copy the files under ` /home/ubuntu/Share/genome_assembly` to your own directory
```
cp /home/ubuntu/Share/genome_assembly/*.fa.gz .
```
## 4. Run
Run analyses

```
asmstats ilVanAtal1.hifiasm.total.p_ctg.fa.gz > ilVanAtal1.hifiasm.total.p_ctg.fa.gz.stats
python3 plot_read_length_dist.py ilVanAtal1.600.fasta
```

Download the pdf file locally and have a look at the plot

```
scp -i <your>.pem ubuntu@44.247.73.6:/home/ubuntu/Share/genome_assembly/results/ilVanAtal1.600_length_dist.pdf .
```
